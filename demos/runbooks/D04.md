# D04. Fabric Core MCP server

![TBC](https://img.shields.io/badge/TBC-FF7A59?style=flat-square) Slide 11 · Recording: [English](../../en/media/S08-A11-core-mcp-audit.mp4) · [Polish](../../pl/media/S08-A11-core-mcp-audit.mp4) · [German](../../de/media/S08-A11-core-mcp-audit.mp4)

The remote Fabric Core MCP server exposes Fabric REST operations as tools. Count how many of them can change your tenant.

## You need

- Nothing beyond your Azure CLI sign-in.

## Steps

1. `python3 fabdemo.py core-mcp init`
2. `python3 fabdemo.py core-mcp tools`
3. `python3 fabdemo.py core-mcp call list_workspaces`

## Expected result

The server name and protocol version, the tool count split into read-only and write tools, and the workspaces you can see.

Output from the verification run on October 21, 2026, trimmed to the demo workspace, IDs replaced:

```text
$ python3 fabdemo.py core-mcp init
FabricMCPServer 13.0.28520.305  protocol 2025-11-25

$ python3 fabdemo.py core-mcp tools
27 tools: 12 read-only, 15 write
write: create_workspace, update_workspace, delete_workspace, add_workspace_role, update_workspace_role, delete_workspace_role, create_item, update_item, delete_item, update_item_definition, bulk_move_items, create_folder, update_folder, delete_folder, move_folder

$ python3 fabdemo.py core-mcp call list_workspaces
  My workspace             Personal
  fabcon-recap-demo        Workspace
```

## Time and cost

About 2 minutes. No Fabric capacity needed.
