# D03. Fabric IQ MCP server

![GA](https://img.shields.io/badge/GA-1F7A4D?style=flat-square) Slide 11 · Recording: [English](../../en/media/S08-A2-fabric-iq-mcp.mp4) · [Polish](../../pl/media/S08-A2-fabric-iq-mcp.mp4) · [German](../../de/media/S08-A2-fabric-iq-mcp.mp4)

The read-only Fabric IQ MCP server: list its tools, find the semantic model by name, and run a DAX query as the signed-in user.

## You need

- The `Oud RnD` semantic model from `up`.
- The `PowerBIMCP` tenant setting, part of `settings on`.

## Steps

1. `python3 fabdemo.py iq-mcp tools`
2. `python3 fabdemo.py iq-mcp discover "Oud RnD"`
3. `python3 fabdemo.py iq-mcp dax "Oud RnD" 'EVALUATE SUMMARIZECOLUMNS(formulas[formula_name], "Preference %", [Avg first choice %]) ORDER BY [Preference %] DESC'`

## Expected result

Six read-only tools, the model found by name, and the average first-choice share per formula with Oud Saffron S-7 on top at 68.

## Time and cost

About 3 minutes. Queries use the capacity, which must be Active.
