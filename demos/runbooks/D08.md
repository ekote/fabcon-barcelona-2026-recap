# D08. Ontology agent in Fabric IQ

![PREVIEW](https://img.shields.io/badge/PREVIEW-B85C00?style=flat-square) Slide 15 · Recording: [English](../../en/media/S12-A8-ontology.mp4) · [Polish](../../pl/media/S12-A8-ontology.mp4) · [German](../../de/media/S12-A8-ontology.mp4)

The ontology agent reads the semantic model, plans entity types and relationships, and applies the plan when you switch to Act mode.

## You need

- The `Oud RnD` semantic model from `up`, with Read and Build permission.
- The `OntologyPreview` tenant setting, part of `settings on`.

## Steps

1. In the workspace, select **New item** > **Ontology (preview)** and create an empty ontology.
2. Open **Ontology agent**. It starts in **Plan** mode.
3. Send the first prompt below and wait for the plan.
4. Switch to **Act** mode and send the second prompt.

## Prompts

**English**, prompt 1

```text
Build an ontology from the Oud RnD semantic model: formulas, ingredients, preference trials, and how they relate.
```

**English**, prompt 2

```text
Apply this plan.
```

**Polish**, prompt 1

```text
Zbuduj ontologię z modelu semantycznego Oud RnD: receptury, składniki, testy preferencji i ich relacje.
```

**Polish**, prompt 2

```text
Zastosuj ten plan.
```

**German**, prompt 1

```text
Bau eine Ontologie aus dem semantischen Modell Oud RnD: Rezepturen, Inhaltsstoffe, Präferenztests und wie sie zusammenhängen.
```

**German**, prompt 2

```text
Setz diesen Plan um.
```

## Expected result

A plan with six entity types and five relationships, then the same entities on the canvas.

## Time and cost

About 8 minutes. Runs on the F8 capacity from `up`.
