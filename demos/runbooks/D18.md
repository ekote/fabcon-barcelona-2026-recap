# D18. OneLake table APIs: Unity Catalog and Iceberg REST

![GA](https://img.shields.io/badge/GA-1F7A4D?style=flat-square) Slide 30 · Recording: [English](../../en/media/S16-onelake-open-catalogs.mp4) · [Polish](../../pl/media/S16-onelake-open-catalogs.mp4) · [German](../../de/media/S16-onelake-open-catalogs.mp4)

The same Delta tables seen through a Unity Catalog compatible API and through the Iceberg REST Catalog, with no copy.

## You need

- Tables loaded by `up`.
- For the Iceberg calls, Delta to Iceberg metadata conversion on for the tenant or workspace.

## Steps

1. `python3 fabdemo.py uc formulas`
2. `python3 fabdemo.py irc`
3. `python3 fabdemo.py irc preference_trials`

## Expected result

The `formulas` table as Delta with seven columns, the table list through Iceberg, and `preference_trials` as an Iceberg table.

Output from the verification run on October 21, 2026, trimmed to the demo workspace, IDs replaced:

## Time and cost

About 2 minutes. Calls are small, the capacity must be Active.
