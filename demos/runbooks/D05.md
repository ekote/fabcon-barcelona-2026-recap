# D05. OneLake Table Read API

![PREVIEW](https://img.shields.io/badge/PREVIEW-B85C00?style=flat-square) Slide 12 · Recording: [English](../../en/media/S09-A17-table-read-api.mp4) · [Polish](../../pl/media/S09-A17-table-read-api.mp4) · [German](../../de/media/S09-A17-table-read-api.mp4)

An app reads a Delta table over REST as Apache Arrow streams, with no Spark cluster, and OneLake security filters rows and columns for the caller.

## You need

- Tables loaded by `up`.

## Steps

1. `python3 fabdemo.py table-read preference_trials formula_id,panel_segment,n_testers,first_choice_pct`

## Expected result

One Arrow stream with the seven preference trials and only the four requested columns.

Output from the verification run on October 21, 2026, trimmed to the demo workspace, IDs replaced:

## Time and cost

About 1 minutes. Each `POST /read` is billed to the capacity.
