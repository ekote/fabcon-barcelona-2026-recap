# D14. OneLake catalog search API

![PREVIEW](https://img.shields.io/badge/PREVIEW-B85C00?style=flat-square) Slide 26 · Recording: [English](../../en/media/S16-A20-catalog-search.mp4) · [Polish](../../pl/media/S16-A20-catalog-search.mp4) · [German](../../de/media/S16-A20-catalog-search.mp4)

Search the whole tenant from code, by name or by description, and the same search as a Core MCP tool.

## You need

- Items from `up`, so the search has something to find.

## Steps

1. `python3 fabdemo.py catalog-search oud`
2. `python3 fabdemo.py catalog-search synthetic Lakehouse,SemanticModel,Eventhouse`
3. `python3 fabdemo.py core-mcp call search_catalog '{"search":"oud","pageSize":5}'`

## Expected result

Hits across item types for "oud", then only lakehouses, semantic models, and eventhouses whose description says synthetic, then the same search through MCP.
