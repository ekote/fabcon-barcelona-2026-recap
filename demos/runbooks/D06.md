# D06. Project Osmos, the data engineering agent

![PREVIEW](https://img.shields.io/badge/PREVIEW-B85C00?style=flat-square) Slide 13 · Recording: [English](../../en/media/S10-A5-osmos.mp4) · [Polish](../../pl/media/S10-A5-osmos.mp4) · [German](../../de/media/S10-A5-osmos.mp4)

Osmos receives one data engineering outcome, plans it, runs notebooks on SparkCore, and validates the result. The task persists in the lakehouse.

## You need

- GitHub Copilot CLI, Codex, or another coding agent with the Skills for Fabric plugin.
- A workspace without outbound access protection. Osmos does not run in a protected workspace.

## Steps

1. Sign in with `az login` to the tenant that holds the workspace.
2. Start `copilot`, then run `/plugin marketplace add microsoft/skills-for-fabric` and `/plugin install fabric-skills@fabric-collection`. Restart and check `/skills` for `project-osmos`.
3. Send the prompt below. Review the eight settings card (permission boundary, safety pattern, rerun rules, schema evolution) and accept it.
4. Open the lakehouse **lh_oud_rd** in Fabric and select the task under **ProjectOsmos**. Watch **Execution plan** and **Activity**.
5. Open the result table `gold_formula_scorecard`.

## Prompt

**English**

```text
Create a Project Osmos task in the workspace <your workspace> and the lakehouse lh_oud_rd. Build a gold table gold_formula_scorecard with one row per formula: formula name, cost per kg, average first-choice share across all trials, and the optimizer saving in percent. Use the tables formulas, formula_metrics, preference_trials, and formula_optimization. Save the logic as a notebook 02_gold_scorecard. Validate one row per formula, no null costs, and shares between 0 and 100.
```

## Expected result

Six rows. OB-105 Oud Plantation shows 52.5, the average of its two trials (44 and 61), because Osmos averages trials before the join.

## Time and cost

About 20 minutes. The task runs on the capacity for about 15 minutes.
