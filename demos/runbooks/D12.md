# D12. Policies in Fabric

![PREVIEW](https://img.shields.io/badge/PREVIEW-B85C00?style=flat-square) Slide 18 · Recording: [English](../../en/media/S15-A13-policies.mp4) · [Polish](../../pl/media/S15-A13-policies.mp4) · [German](../../de/media/S15-A13-policies.mp4)

Fabric policies are allow lists scoped to the tenant or a capacity. The demo opens the policy that controls which workspace admins can edit security settings.

## You need

- The `PolicySetTenantSwitch` tenant setting, part of `settings on`, and the Fabric administrator role.
- A capacity outside West Europe, North Europe, and West US, where policies are not supported yet.

## Steps

1. Open **OneLake catalog** > **Govern** > **Policies (preview)**.
2. Switch between **Fabric tenant** and **Capacities**.
3. Open **Workspace admins can edit workspace settings** and read the note to connect a policy set first.

## Expected result

The policy list per scope. Allow is the only effect, there is no deny rule.

## Time and cost

About 3 minutes. No Fabric capacity needed.
