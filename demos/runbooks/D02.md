# D02. The AI setting on a semantic model

![GA](https://img.shields.io/badge/GA-1F7A4D?style=flat-square) Slide 8 · Recording: [English](../../en/media/S05-A12-semantic-model-ai-setting.mp4) · [Polish](../../pl/media/S05-A12-semantic-model-ai-setting.mp4) · [German](../../de/media/S05-A12-semantic-model-ai-setting.mp4)

One setting per semantic model decides whether people with read access can use Copilot, Microsoft 365 Copilot Chat, the data agent, and remote MCP tools on it.

## You need

- The `Oud RnD` semantic model from `up`, and write permission on it.

## Steps

1. Open the workspace, then the settings of the **Oud RnD** semantic model.
2. Expand **Explore and AI access**.
3. Find **Allow any person with only read permissions to use AI**. It is on by default.
4. Turn it off on a model with sensitive data, then check a model built on top of it: the setting does not carry over.

## Expected result

The setting is on for a new model. Each model has its own switch, including models chained on another model.

## Time and cost

About 2 minutes. Runs on the F8 capacity from `up`.
