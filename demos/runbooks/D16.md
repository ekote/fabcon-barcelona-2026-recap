# D16. Materialized lake views with data quality rules

![GA](https://img.shields.io/badge/GA-1F7A4D?style=flat-square) Slide 28 · Recording: [English](../../en/media/S16-mlv-medallion.mp4) · [Polish](../../pl/media/S16-mlv-medallion.mp4) · [German](../../de/media/S16-mlv-medallion.mp4)

Bronze, silver, and gold in SQL. Silver drops rows that break three constraints, and lineage shows how many it dropped.

## You need

- The notebook `05_mlv_medallion` and the schema-enabled lakehouse `lh_oud_mlv` from `up`.

## Steps

1. Open the notebook **05_mlv_medallion** and select **Run all**. The last cell appends three bad rows to bronze.
2. Open **lh_oud_mlv** > **Materialized lake views** > **Manage** to see the lineage: bronze, silver, gold.
3. Select **Run**, give the run a name, and run it.
4. Open **Recent run(s)**, select your run, and expand the activity table.

## Expected result

Gold has one row per formula. The run shows **Dropped rows: 3** on `silver.trials_clean`.

## Time and cost

About 10 minutes. Runs on the F8 capacity from `up`.
