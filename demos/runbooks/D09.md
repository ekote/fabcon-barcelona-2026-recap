# D09. Copilot generates a Real-Time Dashboard

![PREVIEW](https://img.shields.io/badge/PREVIEW-B85C00?style=flat-square) Slide 16 · Recording: [English](../../en/media/S13-RTI-copilot-dashboard.mp4) · [Polish](../../pl/media/S13-RTI-copilot-dashboard.mp4) · [German](../../de/media/S13-RTI-copilot-dashboard.mp4)

Copilot for Real-Time Intelligence turns one sentence into a dashboard on live blotter test events.

## You need

- The eventhouse `eh_oud_trials` from `up`. Its 3,000 events cover the eight hours before you load them, so reload right before the demo: `python3 fabdemo.py eventhouse`.

## Steps

1. Open the KQL database **eh_oud_trials**.
2. Select **Real-Time Dashboard** > **Generate with Copilot**.
3. Send the prompt below and follow the reasoning in the pane.
4. Select **Start dashboard creation**, then **Create**.

## Prompt

**English**

```text
Preference test dashboard: first-choice share over time for each formula, a comparison of booths, and testers per hour.
```

**Polish**

```text
Dashboard testów preferencji: udział wyborów testu w czasie dla każdej receptury, porównanie stoisk i liczba testerów na godzinę.
```

**German**

```text
Dashboard für Präferenztests: Anteil der Erstwahl im Zeitverlauf pro Rezeptur, Vergleich der Stände und Testpersonen pro Stunde.
```

## Expected result

A new dashboard with tiles for first-choice share per formula over time, booth comparison, and testers per hour. Tile layout varies between runs.

## Time and cost

About 5 minutes. Runs on the F8 capacity from `up`.
