# D01. The "Fabric data in Microsoft Copilot" setting

![GA](https://img.shields.io/badge/GA-1F7A4D?style=flat-square) Slide 8 · Recording: [English](../../en/media/S05-A23-copilot-admin-setting.mp4) · [Polish](../../pl/media/S05-A23-copilot-admin-setting.mp4) · [German](../../de/media/S05-A23-copilot-admin-setting.mp4)

The Microsoft 365 admin center setting that lets Microsoft 365 Copilot reach Power BI and Fabric data. It is on for all users by default.

## You need

- Access to Copilot settings in the Microsoft 365 admin center.

## Steps

1. Open [admin.cloud.microsoft](https://admin.cloud.microsoft) and go to **Copilot** > **Settings** > **View all**.
2. Select **Fabric data in Microsoft Copilot**.
3. Read the two parts of the setting: people can search and retrieve Fabric data, and which users it applies to.
4. Check **Allow users to access**. The default is **All users**.

## Expected result

The panel shows the setting turned on for **All users**. Decide whether that matches your data policy before anyone asks Copilot about finance data.

## Time and cost

About 2 minutes. No Fabric capacity needed.
