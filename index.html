FabCon Europe 2026 in Barcelona: what shipped in Microsoft Fabric, and what's still preview

FabCon and SQLCon Europe 2026 ran from September 28 to October 1, 2026, in Barcelona. The keynote on September 29 turned Microsoft Fabric into a platform for agents: Microsoft 365 Copilot Chat, MCP clients, Copilot Studio, and apps can now pull answers from Fabric data. This recap labels every announcement GA, PREVIEW, ROADMAP, or TBC, checked against Microsoft Learn on October 21, 2026. It comes with slides in English, Polish, and German, PDFs, 20 recordings from a demo tenant with synthetic data, and a script that rebuilds the demos in your own tenant.

Key takeaways from FabCon Europe 2026

  • Fabric data now leaves Fabric through three doors: Copilot Chat and Cowork, MCP servers, and Copilot Studio plus the OneLake Table Read API. Each door enforces the user's permissions, so the real question is who set them.
  • Two settings are on by default in every tenant: "Fabric data in Microsoft Copilot" in the Microsoft 365 admin center, and the AI setting on every semantic model.
  • Much of what was announced is preview. Turn on what is GA, pilot what is preview on one workspace, model, or capacity, and put the rest off.

Three doors: how Fabric data reaches agents

Before Barcelona, Copilot and the data agent worked inside Fabric, and the answer stayed there. After Barcelona, Fabric answers questions from outside the platform, and the main consumer of the data is now an agent.

  1. Microsoft 365 Copilot Chat and Cowork. A user asks in the chat, and Fabric IQ answers from a semantic model you control.
  2. MCP servers. An MCP client queries Fabric IQ read-only, and Core MCP creates workspaces and items on the user's behalf.
  3. Copilot Studio and the OneLake Table Read API. A data agent works as a tool for another agent, and an app reads Delta and Iceberg tables over REST.

Each door enforces the user's permissions. The question is who set those permissions.

Two Microsoft Fabric settings that are on by default

  • "Fabric data in Microsoft Copilot" in the Microsoft 365 admin center gives Microsoft 365 Copilot access to Power BI data and is on for everyone. Learn
  • The AI setting on a semantic model lets anyone with read-only access use Copilot, Copilot Chat, Cowork, the data agent, and MCP tools. It doesn't carry over to chained models. Learn

Admin checklist: four tenant settings to check after FabCon 2026

  1. Check who can reach Fabric data from Microsoft 365 Copilot. In the Microsoft 365 admin center, open the Copilot settings and find "Fabric data in Microsoft Copilot". It is on for all users by default. Learn
  2. Review the AI setting on sensitive semantic models. Check the AI setting on semantic models with HR and finance data. It lets anyone with read access use Copilot, the data agent, and MCP tools, and it does not carry over to chained models. Learn
  3. Check the cross-region AI tenant settings. Check the tenant settings that let AI process or store data outside the capacity's region and geography. They matter for capacities outside the EU Data Boundary and the US, including the UK. Learn
  4. Turn on outbound access protection where data is sensitive. Turn on workspace outbound access protection for workspaces with sensitive data, so data cannot leave through shortcuts or data agents. Learn

For engineers: test RLS under the data agent on your own model, and tag preview items before someone puts them into production. For CTOs: the agent acts on the user's behalf, read-only, and can't see more than the user. Ask Microsoft whether an agent can run under its own Entra Agent ID.

FAQ

What was announced at FabCon Europe 2026 in Barcelona?

The main announcements: Fabric IQ in Microsoft 365 Copilot Chat and Cowork (GA), the Fabric IQ MCP server (GA), the Fabric Core MCP server, data agents in Copilot Studio, the OneLake Table Read API (preview), Project Osmos (preview), operations agents (preview), a new ontology in Fabric IQ (preview), agentic apps in Power BI Desktop (preview in the coming weeks), OneLake security (GA announced for the coming weeks), policies in Fabric (preview), and on-demand billing with an F0 capacity (roadmap).

Is Fabric IQ in Microsoft 365 Copilot Chat generally available, and does it cost extra?

Yes, it is GA. There is no extra charge for AI tokens, but the queries still use your Fabric capacity, and each user needs a Microsoft 365 Copilot license. Data agents and ontologies answer in Copilot Chat only once they are published as a Microsoft 365 agent.

What is the difference between the Fabric IQ MCP server and the Fabric Core MCP server?

Fabric IQ MCP is a GA, read-only server for Power BI reports and semantic models: search, metadata, and DAX queries under the user's permissions and RLS. Fabric Core MCP exposes Fabric REST operations, and 15 of its 27 tools write changes to workspaces, items, and permissions. Learn warns that autonomous or misconfigured clients may perform destructive actions.

Is OneLake security generally available?

The keynote announced GA for the coming weeks without a date, and Learn gave no GA date on October 21, 2026. OneLake security defines roles, RLS, and CLS once and enforces them across Fabric engines and shortcuts. Every lakehouse has a DefaultReader role. The roles restrict users with Viewer or Read access, while Admin, Member, and Contributor keep broader access.

Does the Fabric data agent support languages other than English?

Officially, no. Learn describes questions in English. The Polish and German demo agents in this repo answered correctly, but outside official support, so test your own language before you rely on it.

Do I need the cross-geo processing setting for Copilot in Fabric?

Not for capacities in the US or inside the EU Data Boundary, which covers the EU and the EFTA countries, Switzerland included. Copilot for a Swiss capacity can still run in an EU datacenter outside Switzerland. Capacities in the UK and other geographies need the setting turned on.

When does the previous ontology experience in Fabric retire?

On January 31, 2027. The new ontology in Fabric IQ, in preview, replaces it.

What is Project Osmos?

Project Osmos is the data engineering agent in Microsoft Fabric, in preview. It plans, runs, and validates data engineering tasks on SparkCore, the tasks persist, and Fabric and OneLake permissions remain the boundary of what it can do. You start it from a coding agent such as GitHub Copilot CLI.

Can I run these demos in my own Fabric tenant?

Yes. The demos folder has a Python script that creates an F8 capacity, a workspace, synthetic data, a semantic model, an eventhouse, notebooks, and a data agent, plus one runbook per recorded demo with the exact prompts and expected results. F8 costs about 1.41 EUR per hour in France Central at the Azure retail price, and the capacity can be paused when you are done.

Run the demos in your own Fabric tenant

The demos folder rebuilds the environment behind the 18 product recordings: one Python script creates the capacity, the workspace, synthetic data, a semantic model, an eventhouse, a failing pipeline, notebooks, and a data agent.
