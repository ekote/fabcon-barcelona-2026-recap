## What's inside

The talk asks one question: Fabric has become a platform for agents, so have our settings kept up?

- **Part 1, what we had:** Copilot and the data agent lived inside Fabric. Two tenant settings that are on by default.
- **Part 2, what shipped:** three doors for data to reach agents (Copilot Chat, MCP servers, Copilot Studio and the OneLake Table Read API), Project Osmos, operations agents, the new ontology in Fabric IQ, Copilot for Real-Time Intelligence, OneLake security, policies, and observability.
- **Part 3, what's still missing:** the roadmap with no spin, what to turn on, what to pilot, what to put off, and a checklist for admins, engineers, and CTOs.
- **Appendix:** five features in action. OneLake catalog search API, AI functions, materialized lake views, the Fabric data agent, and OneLake table APIs.

Every label on a slide is GA, PREVIEW, ROADMAP, or TBC, as checked against Microsoft Learn on October 21, 2026. Statuses change fast, so check Learn before you rely on one.

## The recordings

Each language folder has a `media/` folder with every clip the slides play. The demos ran in a personal demo tenant on synthetic data: an oud perfume house with formulas, ingredients, and preference trials. The English and German folders have their own takes of the demos with typed text, so prompts and agent answers match the language.
